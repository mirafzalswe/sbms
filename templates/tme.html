TME · Авторизация и сценарии

Логин в TME через Flask-прокси, получение токена и запуск сценариев — например, смена тарифного плана через CHANGE_RTPL.

TME Endpoint

URL сервиса https://tme.ucell/login?returnUrl=%2Fcase
API Authenticate POST https://tme.billing.domain/api/v1/authenticate
Сценарий-кейс https://tme.ucell/case/CHANGE_LC_STATE
Run сценария POST https://tme.billing.domain/api/v1/scenarios/<SCENARIO>/run?page=1&page_size=50
Введите логин и пароль — запрос будет отправлен через Flask-прокси, чтобы обойти CORS и SSL-проверку. После успеха в разделе Result появится токен, который можно использовать для следующих запросов.

Смена тарифного плана CHANGE_RTPL

Войдите в TME выше — токен нужен и для загрузки списка тарифов, и для запуска сценария. Тарифы грузятся через POST /api/v1/scenarios/get_rtpl_for_change/run. Смена — через POST /api/v1/scenarios/CHANGE_RTPL/run с телом {"MSISDN":"…","RTPL":"<ID>"}.
