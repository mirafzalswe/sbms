1Продукт для проверки

Введите ID продукта и явно укажите его тип — пакет или услуга. Один и тот же числовой ID может относиться к разным сущностям, поэтому выбор обязателен.

2Список тарифов для проверки

Введите тарифы, на которых проверяется доступность продукта. ID может быть в формате (ID 58) в конце имени, либо отдельным числом в первой колонке.

3Номер абонента и учётки

Введите номер тестового абонента и выберите учётки. Достаточно кликнуть по карточке — пароли уже подставлены.
ADMIN Учётка, которая будет переключать тариф абонента
Под этой учёткой по очереди вызывается смена тарифа на каждый тариф из списка. Введите логин и пароль вручную.
VIEWER Учётка, под которой проверяется доступность продукта
После каждой смены вызывается /packs/search?onlyRealPackFlag=0 (или /services/search) под этой учёткой — в списке подключённых продуктов абонента ищем введённый ID. Можно выбрать пресет или ввести учётку вручную.
