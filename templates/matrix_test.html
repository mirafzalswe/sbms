          3Номер абонента и учётки

          Введите номер тестового абонента и выберите учётки для двух ролей. Пароли для пресетов уже подставлены — достаточно кликнуть по карточке.
          ADMIN Учётка, которая будет переключать тариф абонента
          Под этой учёткой по очереди вызывается смена тарифа на каждый исходный тариф из списка. Введите логин и пароль вручную.
          VIEWER Учётка, под которой проверяется список доступных переходов
          После каждой смены вызывается availableForChange/search под этой учёткой — полученный список сравнивается с целевыми тарифами в матрице.

          4Запуск

          Будет проверено 0 исходных тарифов из 0. Изменить выбор можно на шаге 2.
          ⚠ Внимание: каждая строка матрицы реально переключает тариф на номере. Между переходами есть пауза. Для одной полной матрицы (например 25×12) прогон займёт 5–15 минут.
